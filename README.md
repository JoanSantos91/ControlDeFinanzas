# Mi Libertad Financiera — Streamlit V1

Esta versión NO usa Supabase. Usa SQLite (`finance_data.db`) dentro de la aplicación.

## Subir a GitHub
Sube:
- app.py
- requirements.txt
- assets/
- .gitignore

## Crear en Streamlit Community Cloud
Selecciona el repositorio y usa:
Main file path: app.py

## Importante
El almacenamiento local de Streamlit Cloud no debe considerarse permanente.
La app incluye una pestaña **Respaldo** para descargar y restaurar el archivo `.db`.
Más adelante se puede migrar esta misma estructura a Supabase.
